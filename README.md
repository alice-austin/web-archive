# web-archive-registry

This repository is the authoritative source for information on archive captures of UE websites.

## RULES
- One URL per row
- URLs must be unique
- Trailing slash is required
- The following fields are required:
  - Seed URL
  - Business area 1
  - Business area 2
  - Type
  - URL status
  - Preservation status
  - Licence status

 ## WORKFLOW
 1. Create a branch
 2. Edit registry.csv
 3. Open a pull request
 4. Validation runs automatically
 5. Review
 6. Merge
 7. Sharepoint is updated automatically
